# 驭舟两端 App

消费端 `consumer` 与销售端 `broker` 是独立 UniApp Vue3 项目；共用 `shared` 中的接口、订单流程和视觉组件。它们分别生成 H5 和 Android/iOS 原生应用资源，不共用 AppID 或包名。

## 启动与构建

在各自目录执行 `npm ci`，然后 `npm run dev`。本地 H5 `/api` 代理到 `http://127.0.0.1:8088`。测试账号由根目录开发环境初始化产生，App 不内置口令。

地图页先在 `apps/map` 执行 `npm ci` 与 `npm run build`，两端开发服务器 `/boat-map/` 读取该产物。发布时同一产物放在站点 `/boat-map/`；地图只显示已发布实船的录入位置，不请求 GPS。

- `npm run check`：路由文件、Vue 模板、独立 App 身份，以及金额/租赁日期、原生PDF失败保护和短信状态行为检查。
- `npm run build`：输出 `dist/build/h5`，H5 使用 `/consumer/` 或 `/broker/`，默认同源 `/api/v1`。
- `npm run build:app`：输出 `dist/build/app` 原生资源。将该目录导入 HBuilderX 运行或打包。也可将项目目录作为 UniApp CLI 项目导入，源码清单位于 `src/manifest.json`。

原生接口默认 `https://yuzhou.ourideas.top/api/v1`；本地设备测试可以在 `.env.local` 设置 `VITE_API_BASE=http://本机局域网IP:8088/api/v1`，再重新编译。正式包不要保留本地地址。原生资源编译不等于 APK/IPA 签名打包，也不等于真机验收。

## 已接业务

用户端底部为“船艇销售、船艇维保、商城、我的”。船艇销售保留租船和买船；维保仅保养维修与升级改装，商城仅周边商品。航海课堂和发现从“我的”进入，语言切换位于“设置”。原 `shop?kind=...` 分类链接仍是普通页面；经纪人端导航保持原样。

消费端：首页租售/搜索/排序/列表切换/对比、四处轮播、置顶资讯、图片与3D平台链接、按日多艘预约、实际船购买与实船选配、升级前后参数/适配型号、维修/自营周边、免费课程学习与考试、六类奖励记录、积分兑换与取消返分、私有身份资料提交/人工审核状态、活动资格/报名/免费取消、论坛发帖审核/评论/点赞/官方回复、会员成长/优惠券、订单报价/合同审核状态/客户确认/支付/退款申请、服务时间地点与安装进度、咨询、带看预约、收藏足迹、船艇记录、保养提醒、反馈与平台回复、评价。

销售端：工作台、客户与跟进/公司标签、公司当月实收与销售目标、地图实船与预选配置、代客订单、报价、PDF合同上传、服务预约与实际进度、交付履约、客户订单链接、佣金账本与幂等提现申请、本人销售统计/分红Excel下载、咨询和带看。公司管理与平台审核在管理后台。

首页推荐使用服务端个人收藏/浏览偏好，有偏好时说明依据；无偏好显示“精选船艇”。地图船型详情同时显示选中实船并在购买时预选，后端仍最终验证实船与库存。

所有可变业务数据、支付金额、权限和库存均由真实 API 返回。支付只在服务端明确开启开发测试通道时显示“开发测试支付”；微信/支付宝、短信和外部打款未配置会展示服务端错误。聊天使用5秒前台轮询，未冒充系统推送。

课程礼包与积分礼品在平台实际履约前显示“待平台履约”；活动奖励仅显示资格，仍须报名。本船3D入口只在该资源已有模型链接时显示，演示船不匹配其他船艇模型。全局3D入口读取服务端 `vr_base_url`。型号目录购买模式显示“实船报价”，选择真实船艇后展示售价，支付金额仍以订单为准。

活动报名须平台人工身份资料审核通过且会员有效；身份材料默认私有，不接入未配置的外部实名服务。审核通过会失效旧登录，须重新登录查看最新状态。免费报名未签到时可取消释放名额；重新报名产生新票，旧票不能取消新报名。付费报名通过对应订单处理取消或退款申请。

两端保留账号密码登录，并提供已验证手机号的验证码登录；消费者可验证码注册普通账号，销售端不提供匿名注册销售身份。已登录用户可在个人页验证并绑定本人手机号，已有不同号码不能自动换绑。客户端使用服务器challenge、用途、有效期与重发冷却，验证码保留前导零；短信平台受理后显示“受理不代表已送达”，结果未知或供应商拒绝均保留冷却。缺少短信配置会显示实际错误。绑定输错验证码不会清除有效登录，真正登录过期仍须重新登录；身份不匹配时撤销该次返回的登录授权。

## 当前设备边界

H5 支持系统文件选择并真实上传 PDF；Android 通过系统 `ACTION_OPEN_DOCUMENT` 导入 PDF；iOS 通过系统 `UIDocumentPickerViewController` 导入 PDF，App 也支持合同下载预览。原生导入桥接仍需各平台真机验证，若设备运行失败可先使用销售 H5 上传。Android/iOS 真机文件选择、支付、视频和3D交互需分别验收。正式隐私政策/服务协议、签名证书与支付/短信参数由运营方提供，测试界面中的同意提示不能代替正式法律文本。
