## 真实本地验证

2026-10-09，独立开发库、真实本地 `/api/v1` 和 Chromium 页面；未拦截 API。所有新数据、企业资料和合同均明确标记为合成开发资料。

- `tests/live-management.cjs`：11 项。三个入口实际登录；商家、经纪公司、平台均上传并鉴权预览 PDF；平台合同审核；商家/经纪公司履约；显式会员受益人及整数利润；未配置真实退款通道拒绝且状态不变；测试部分退款冻结；复核保持原会员及5%后净账本1750分；商家不能读取经纪公司订单或其私有 PDF、经纪公司不能读取商家直单、匿名不能读取私有 PDF。
- `tests/live-content.cjs`：7 项。六种奖励实际配置及券/活动外键；合成学习进度与考试触发奖项；活动只发资格；实物交付凭据；指定商家联合活动审核；预约确认完成；咨询回复；实际反馈可见。
- `tests/live-operations.cjs`：8 项。真实授权统计；鉴权 Excel 文件下载；用户历史；积分兑换驳回精确恢复积分/库存；交付凭据；真实上传轮播图片；资讯/置顶/待审评论/官方回复；仅订单模块的子角色隐藏财务菜单、阻止直接页面，服务端财务/报表接口返回403。
- `tests/live-service.cjs`：7项。三入口未来预约及本地时区、真实40%记录、公司订单供应商404、平台记录回读、浏览器/API拒绝进度回退、100%不完成订单、无页面异常。
- `tests/live-crm.cjs`：8项。公司标签创建/赋予/实际关系过滤、跨公司与商家拒绝、公司月目标及平台编辑/停用、当月支付减退款范围增量、提现同key同金额返回同ID且仅reserve一次（换金额409）、无页面异常。
- `tests/live-map.cjs`：8项。初始真实API无坐标空态；Web成对/范围拦截及WGS84 typed小数；仅新合成船审批后marker→消费者详情/购买预选及经纪人实船配置预选；两项清空、已有坐标不变、无异常。无API mock，所有外网/OSM瓦片被拦截，不验证正式底图/真实泊位/native桥接。
- 反馈回复另行实际页面验证：平台回复持久化为 `handled`，用户接口可读取回复，并收到对应站内通知。
- 导出的 `.xlsx` 经 `unzip -t` 验证内容类型、关系、工作簿及工作表结构文件完整。

以上真实Web/API/H5检查合计49项，反馈另3项。运行报告及截图在 `test-results/live-management`、`live-content`、`live-operations`、`live-service`、`live-crm`、`live-map`、`live-feedback`，已忽略，不提交业务资料。`tests/browser-smoke.cjs` 的11项检查使用合成 API 夹具，仅作前端回归，不作为上述真实服务端证据。`tests/withdrawal-retry.cjs`另有3项组件级合成夹具，验证失败同金额复用键（含10/10.00格式）、成功新申请换键、金额变化换键，不能算真实交易；真实同key无重复预留证据在live-crm。

私有文件权限修复后，真实本地只读HTTP另6项通过（`/tmp/yuzhou-analysis/private-file-boundary-fixed-report.json`）：仅orders平台子账号拒绝他人身份PDF及营业执照、保留实际关联合同读取；文件本人及全权限平台可读，匿名403。使用已有合成记录，不改数据或角色，未走浏览器操作，因此不计入上面的49项页面检查。后端 `private-files` 18项已分别在本地PHP8.2及阿里云PHP7.2.33通过，各环境当前后端244项；这6项的远端HTTP和公开HTTPS结果尚未取得。

真实支付/退款/提现、短信、微信/Apple 登录、原生推送、保险/金融/船艇系统、外部电子签与 AI 审核尚未配置，不报告成功。未验证 iOS/Android 原生包、Safari 文件选择器完整兼容、生产部署、性能指标及实际视频观看或配送。本 Web 验证了商家与经纪订单归属边界；第二家经纪公司的完整页面回归需另有独立证据。
