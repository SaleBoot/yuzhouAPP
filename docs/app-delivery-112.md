# 1.0.12 强制热更新

用户反馈部分旧版首页显示 `URL is not defined`，广告和船艇列表加载失败。本次将用户端和经纪人端分别发布为 1.0.12 / 112，统一分发现有兼容修复；原生 App 的媒体地址拼接不依赖浏览器 `URL` 构造器。两个 AppID、包名、5.26 运行库和业务流程保持既有配置。

两份 WGT 元数据均设置布尔值 `mandatory: true`。已有 1.0.9–1.0.11 的客户端联网启动或回到前台时检查新版本，确认后必须完成下载、身份及 SHA256 校验、安装和重启才能继续。1.0.8 及更早客户端没有启动自动检查，必须先进入一次“我的 → 应用更新”；服务端元数据不能远程补上尚未执行的客户端代码。WGT 不延长 iOS 原生签名。

实际发布只切换本站 WGT 更新目录，保留历代 WGT、原生安装包、网页、地图、后端、配置、数据库和上传资料。实际源提交、两包 SHA256、HTTPS 校验和发布结果记录在独立回执；自动测试、线上文件校验和真机安装分别记录，不将发布成功视为全部设备已升级。

本文件为源码中的交付说明；构建与线上发布结果以 `artifacts/app-updates-112-<提交短码>/delivery-acceptance.json` 为准。
