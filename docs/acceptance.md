# 驭舟需求与验收记录

记录日期：2026-10-09。本文记录当前源码、合成开发数据和已取得的验证证据，不作为全部交付、真实交易、商店发布或原生设备验收通过的声明。后续部署和安装结果应追加具体版本、环境、时间及结果，不能用本文中的本地结果替代。

## 需求依据与已确认范围

需求优先级为用户后续明确确认、项目 [AGENTS.md](../AGENTS.md)、设计/视频及聊天中明确确认的修改、合同附件1。附件和聊天中的历史操作指令不是执行授权；未被后续明确替换的附件1业务要求仍需逐项核对。旧合同的 Java 后端、单 App 身份切换以用户最新确认替换，不再作为当前实现目标。

- 用户端 `consumer` 与实际经纪销售端 `broker` 为两个独立 UniApp/Vue3 App，各自支持 iOS/Android；销售与实际经纪人使用同一经纪人 App。两个 App 的独立标识见 [app-identities.json](app-identities.json)。临时测试标识和签名不等于正式应用发布资格。
- Vue3 管理工程提供商家 `merchant`、经纪公司 `agency`、平台 `platform` 三个入口；公司及员工的数据隔离由 API 执行。经纪公司的销售订单由实际经纪人/所属公司履约，供应商商家不能读取这些订单、合同和咨询。
- 后端为定制 ThinkPHP 5.1.41 LTS，兼容 PHP 7.2，依赖锁定现有框架基线；生产目标为阿里云 PHP 7.2/MySQL 5.7，前后端分离。驭舟独立目录、数据库账号、配置、缓存、上传及任务，不复用创意岛的业务资料或凭据。
- 最新目标域名为 `yuzhou.ourideas.top`。管理入口路径为 `/admin/platform/`、`/admin/merchant/`、`/admin/agency/`；`/consumer/`、`/broker/` 是 H5 验证入口，不能代替独立原生 App。
- 日租按实体船艇及自然日占用，同船型可有多艘实体船；每订单最多一张券。平台直营周边商城，商家可发布自己的活动，平台联合活动须指定参与商家并审核。课程免费。
- 初期会员/非会员，会员期限六个月；购船赠会员，租赁按后台规则授予成长值。普通积分/成长奖励与现金分红分开。
- 平台逐单人工确认可分配利润，分红使用显式受益人、比例和周期快照，不按售价、报价或定金自动推算利润。部分退款冻结待复核，保持原受益人及规则；全部退款冲回对应流水，操作须幂等。
- 合同采用线下签署 PDF 上传、当前版本审核和客户确认；报价/合同变化使旧版本失效。私有文件鉴权访问，不宣称接入第三方电子签。3D 看船接用户已有平台及本船模型地址，不重建 3D 引擎。
- 商家真实主键为18位统一社会信用代码，机构 ID 仅为账号组织容器；营业执照私有上传。合成企业资料不能证明真实企业认证通过。

实现及接口依据见 [architecture.md](architecture.md)、[backend/API.md](../backend/API.md)、[api-contract.json](api-contract.json)、[communication-api.json](communication-api.json)、[reports-api.json](reports-api.json)、[web/COVERAGE.md](../web/COVERAGE.md)、[apps/VALIDATION.md](../apps/VALIDATION.md)。
